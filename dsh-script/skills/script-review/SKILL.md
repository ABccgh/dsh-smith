# 从五维读数到改稿

这份技能接的是 `script-delivery` 的第三、四步：**读数回来了，改哪儿、怎么知道改了有用**。
它不负责交付纪律（那是 `script-delivery`），也不负责平台能力边界（那是 `youxi-platform`）。

> ⚠️ **先把量纲说清，否则下面每一个数字都会被用错。**
> 有戏AI 的读数是 **0–100 总分 ＋ 五维各 0–10**（五维均分 ×10 就是总分，`rules.mjs:686-690`）。
> **不同评估方的两次读数不可相减** —— 见第八节，这条是硬规则，不是谨慎。

## 一、五个维度：id、名字、顺序都是固定的

`D:\dsh-duanju-script\lib\rules.mjs:604`：

```js
export const DIMENSION_IDS =
  Object.freeze(['characterization','emotion_payoff','suspense_retention','narrative_pacing','dialogue_visuals'])
```

源码对它的说明是「**实测自 `评估报告-回填.json` 的 `quantitative_scores`。顺序固定，反了就是漂移**」
（`rules.mjs:603`）。中文名来自平台返回的 `name` 字段，`youxi-platform` 技能第六节逐字记过同一份形状：

| # | id | 名字 | **它在正文里的落点**（本工作台的对应，非平台定义） |
| --- | --- | --- | --- |
| 1 | `characterization` | 人设张力 | 人物的**矛盾式**两端是否都在正文里出现过；外观锚点是否可画（`dramaturgy` 第三节、`episode-engineering` 第四节） |
| 2 | `emotion_payoff` | 情绪爽点 | 付费点与钩子的**兑现**：第 3 集的钩子到第 7 集有没有给（`dramaturgy` 第四节、`hook-ladder` 第四节） |
| 3 | `suspense_retention` | 卡点悬念 | 每集的 `hook3s` 与 `cliffhanger`：开场 3 秒与集尾可接住性（`hook-ladder` 第二、三节） |
| 4 | `narrative_pacing` | 叙事节奏 | 集数与**每集字数分布**、分集功能表是否每集只承担一个功能（`episode-engineering` 第一、二节） |
| 5 | `dialogue_visuals` | 台词画面 | 台词行的密度与可画性；场景台词比（`script-rules` 第四节） |

**表里第三列是本工作台自己建立的一一对应，不是平台公布的定义 —— 标为推断。**
平台没有公布这五个维度各自读正文的哪一部分。**要证伪它**：拿一次读数里明确下降的那个维度，
去比对你这一轮实际改动的部位 —— 如果对不上，就是这张表错了，不是读数错了。

⚠️ **顺序不是审美问题。** `rules.mjs:681-683` 会把读到的 id 序列与 `DIMENSION_IDS` 逐位比对，
不一致就直接报「五维 id/顺序与平台不一致」，也就是说**顺序错的那份回填件是判不了的**。

## 二、评级阶梯与可发布集合

`rules.mjs:591-598` 的 `GRADE_LADDER`（源码注明「原文读自平台前端产物，
工作台在 `script-gate.mjs:540-547` 里另存了一份。两份一致」）：

| 总分 | 等级 |
| --- | --- |
| ≥95 | **S+** |
| ≥90 | **S** |
| ≥85 | **A+** |
| ≥80 | **A** |
| ≥70 | B |
| ≥60 | C |
| <60 | **D** |

`<60` 的 `D` 不是表里的一档，而是「落在表外最低档以下」由 `gradeForScore` 的兜底返回
（`rules.mjs:606-610`）。

**可发布集合**是 `['S+','S','A+','A']`（`rules.mjs:601`，引的是平台原文
`if (!['S+','S','A+','A'].includes(grade))` ⇒ 只能发布 A 级以上）。

⚠️ **`grade` 是算出来的，不是抄来的。** `checkBackfill` 会按 `overall_score` 现算一次
（`rules.mjs:664-671`），抄错就报「`grade` = …，但按总分 … 算出的评级是 …」。
**引用等级时给分数**，两者对不上就是转述错了。

⚠️ **评级不是发布门槛的全部。** 平台侧还有六条（重复提交、<10 集、未生成、未评估…）——
逐条见 `youxi-platform` 技能第五节。评级只过一条。

## 三、`评估报告-回填.json` 怎么读

**路径**：`products\<剧名>\评估报告-回填.json`。`duanju_recall` 的工具参数 `backfillFrom`
可以覆盖它，缺省就是这一条（`D:\dsh-duanju-script\lib\index.js:677`、`:808`）。

**形状**（`rules.mjs:612-620` 记着它的来历，值得逐字读一遍）：
这份 schema「逐字节取自 `git show d634598:products/金枝/评估报告-回填.json`（15 720 字节，
sha256 `6D4BE1E4F656FB03A637CE5E16EA8928B699DF52DCEF92789A10113BBF143016`）」，
而**盘上已无该文件** —— 它随被删的项目一起消失了。
**⇒ 你手上不会有第二份参照。读到形状不对时，那是「判不了」，不是「这个文件坏了」。**

`checkBackfill`（`rules.mjs:633-710`）校验四件事，**每一件都只证明这个文件自洽**：

1. **顶层便捷副本与 `readings[]` 末条一致** —— 逐键比 `overall_score` / `grade` / `评估时间`
   （`rules.mjs:657-662`）。不一致时源码的原话是「同一批事实的两份副本已经分叉」。
2. **`grade` == 按总分现算的等级**（`rules.mjs:664-671`）。
3. **五维的 id 与顺序与 `DIMENSION_IDS` 逐位相同**（`rules.mjs:679-683`）。
4. **五维均分 ×10 与总分相符，容差 2**（`rules.mjs:686-690`，容差照 `E19b`）。

**判不了而不是通过的三种情形**（源码里都是 `UNAVAILABLE`）：不是 JSON 对象、
没有 `readings[]` 数组、`readings[]` 是空的（`rules.mjs:636-654`）。
三种都会明说「**不是通过，是判不了**」。

**工具每次都印、引用时也必须带上的那段限度**（`rules.mjs:705-709`，逐字）：

> ⚠️ 这份检查只证明**这个文件自洽**，它不证明读数本身可信：
> · 读数通常是用户在会话里的**转述**，本机没有该平台的登录态 ⇒ 自洽性检查抓的是转述错字，
> **抓不出整份报告读错**。
> · 它**不预测评级**，也不产生诊断。平台只给分不给诊断时，如实说"这一次没有诊断"。

另外两个要读进去的字段：`被测正文规模`（`rules.mjs:672`，会印出来）——
**它告诉你这次读数测的是哪一版正文**，本项目有过三个版本的三次读数被混着比的事故；
以及任何以 `_⛔` 开头或含「已冻结」的顶层键 —— 发现时会印
「**引用它的数字前先读那一段**，历史读数不代表当前版本」（`rules.mjs:695-697`）。

## 四、读数怎么追加

**只追加 `readings[]`，不改旧条目**（`drama-project-memory` 第一层表）。
追加完再同步三样：顶层的 `overall_score` / `grade` / `评估时间`（第二节的校验就是比这三个键）、
`_待我做的`（当前真实的阻塞项）、以及 `_真实性说明` 与 `_原报告来源`（这一条读数是转述）。

**顺序是有理由的：先追加，再跑自洽检查。** 反过来跑的话，判的是上一次的状态，
那次结论是假的。自洽检查现在由 **`duanju_recall`** 承担（旧口径里那一条叫 `E19b`，
它属于闸门的 `series` 范围；那个范围在本 preset 内已被移除 —— 见 `script-delivery` 第三节）。

**追加完要报四件事**：这一次的五维、与上一次的逐维差、总分与等级的移动、
以及「这是用户转述」这个证据等级。没有上一次就写「这是首次读数」。

## 五、⭐ 本工作台唯一一条可复现的「什么改动会登记」

**这是整份技能里最值钱的一段，也是唯一有完整台账的一段。**

出处：`D:\AIVideo\PROJECT.md:155-158`，逐字 ——

> **六次 PageOne 评估、五次改写，综合分一次没动（5.6 × 6）；而 `S8 自证清白语域` 连降三轮：11 → 10 → 9 → 8 处。**
> ⇒ **合成分对逐句改动不敏感，S8 敏感。** 这是整个项目唯一可复现的「什么改动会登记」的证据，完整台账在 D-61…D-68。

**机制**（`PROJECT.md:387-400`、`:347-357`）：每一轮报告里的**示例句**会换掉**我改过的那一句** ——
第 8 轮删掉第 19 集的一句自证式台词，S8 `11 → 10`，它举的第 19 集那句就消失了；
第 9 轮把第 08 集一句改掉，S8 `10 → 9`，示例跟着换；第六次读数 S8 `9 → 8 处（2.3%）`，
而**它点名的三个示例句逐字未动**，「**降的是没被点名的第 9 处**」（`:356-357`）。

⇒ **可用的结论只有一条**：**逐句的删改会在子指标上登记，合成分不会。**
所以「改了一轮，分没动」**不构成「改稿没有生效」的证据** —— 要判改稿有没有生效，
去看**能被追到具体句子**的那类子指标，而不是看合成分。

⚠️ **这条证据的尺子必须一起说，否则它会被误用。** 它是 **PageOne 的 0–10 制**，
测的是**《毕业照》V3**，而那个项目已取消并完全删除（`PROJECT.md:120`）。
它**不是**有戏AI 的 0–100 制，**不能**拿来和任何有戏AI 的分数相减或换算。
它能迁移的只有**机制**那一层：**合成分迟钝，逐句子指标敏感。**

## 六、按读数改稿的动作

1. **只改正文**（`script-delivery` 第五节的允许/不允许清单）。
2. **每一刀都要能指到具体句子或具体场**，并**记下改了哪几集、哪几句** ——
   否则下一轮你无法判断「登记的是不是我改的那一句」，而第五节那条证据正是靠这个才成立的。
3. **改完提醒用户再点一次评估。** 平台**改完不会自动重评**；不点，读数永远停在旧的那次，
   而你会以为流程在往前走（`script-delivery` 第五节）。
4. **字数会被改动影响。** 每一轮改完**重跑 `script-rules` 那一套**（`duanju_gate`
   的 `range: 'script-only'`），确认没有一集掉出 `story.json` 声明的区间 —— 这是改稿
   最常见的自伤：句子改好了，集字数掉到下限以下。

**不允许**：预测评级；把本地判据的通过当成用户的「满意」；
平台只给分不给诊断时**自己编一份诊断**（`youxi-platform` 第六节第 3 条：
「只给分不给诊断」是常态，如实说「这一次没有诊断文字，所以『还差在哪』没有权威答案」）。

## 七、读到一条读数时的四问

1. **它是平台的判决还是本地的判据？**（评级是判决；六类机械契约是判据 —— 两者不可互推）
2. **它测的是哪一版正文？**（`被测正文规模` 与报告时间 vs 正文 mtime；混版比较是本项目付过学费的错）
3. **它是转述还是导出件？**（转述要标；有截图或导出件就补进 `_原报告来源`）
4. **它的量纲是哪一把尺子？**（下一个问题就是第八节）

## 八、三把尺子不可相减（硬规则）

本项目同时用过三个评估方，**量纲不同**（`PROJECT.md:204`、`DECISIONS.md:2432`，同一份结论两处记着）：

| 评估方 | 量纲 | 实测读数 |
| --- | --- | --- |
| 有戏AI | **0–100 总分 ＋ 五维各 0–10** | **A 84.2**（测 V2） |
| 剧云 | **0–100 六维** | **80（A）**（测 V3） |
| PageOne | **0–10** | **5.6**（测 V3） |

**⇒ 任何两个相减都是错的。** 不是「不太准」，是**错的**：量程不同、评级梯子不同、
被测版本也不同（84.2 与 5.6 分别测的是 V2 与 V3）。
**不同评估方的读数不进同一个 `readings[]`** —— 那是给这一部剧、这一个评估方的读数用的。
第二来源要单独落盘，并在回填件里留一个指针（`PROJECT.md:180` 记着这个做法）。

## 九、自检清单

- [ ] 我报的五维**顺序**与 `DIMENSION_IDS` 一致吗？（顺序错 = 判不了）
- [ ] 我报的 `grade` 与它自己的 `overall_score` 对得上吗？（对不上就是抄错了）
- [ ] 我说清了这条读数是**转述**吗？带上了「抓转述错字、抓不出整份报告读错」那句吗？
- [ ] 我**追加**了 `readings[]`（而不是改旧条目）、并把顶层三个键同步了吗？
- [ ] 我在**追加之后**才跑 `duanju_recall` 的自洽检查吗？
- [ ] 我报差值了吗？没有上一次就写「首次读数」吗？
- [ ] 我有没有把两个不同评估方的数字相减？（**不许**）
- [ ] 我把「合成分不动 ≠ 改稿没生效」说清了吗？有没有指出该看哪一类子指标？
- [ ] 这一轮我改的句子，我记下来了并指得出来吗？
