# 项目记忆：四层，各自只装一种东西

**分层的理由**：`PROJECT.md` 与 `DECISIONS.md` 加起来已超过 250 KB，**永远不可能整体注入上下文**。
所以每一层必须能被单独读完，而「哪一种事实进哪一层」要由用途决定，不是由时间决定。

| 层 | 装什么 | 谁在写 | 规则 |
| --- | --- | --- | --- |
| `PROJECT.md` | 架构与契约**已核实**的事实、当前状态、**刻意未完成**的东西 | 每个里程碑之后 | 可以被改写：删掉现在已假的，别让它在原地被矛盾 |
| `DECISIONS.md` | 一个已决的问题：决定、理由、**什么会推翻它** | 决定了什么的时候 | **只追加。永不改写、永不重排。** 改了主意就写一条**新**条目，并点名它取代了哪条 |
| `INVENTORY.md` | 文件与资产的台账（哪些是权威、哪些可再生、哪些不可再生） | 产物面变化时 | 数字只写能从盘上重数出来的；会被改写的那类写**路径**而不是计数 |
| `products\<剧名>\评估报告-回填.json` | 平台评估的**读数**层 | 每次读数回来 | `readings[]` **只追加**；顶层便捷副本同步成最新；维护 `_待我做的` |

会话开始读回项目状态时：**先读 `PROJECT.md` 的最新一节**，再读 `评估报告-回填.json` 的 `_待我做的`，
需要时再查 `DECISIONS.md` 里相关的那几条 —— **不要整份读 `DECISIONS.md`**。

## 一、一条贯穿全部四层的规则：**平台的规则不进记忆层**

平台的评分口径、评级映射、闸门条件、表头列名 —— 这些是**平台侧的事实**，它们会变。
冻结一份进记忆层，下一次平台改动就把它变成谎话，而且没有任何检查会因此变红。

**它们以「引用」的形式旅行**：写进技能或回填文件时，带上出处（哪个前端产物、哪一行、什么时候读的）。
记忆层里留下的是**项目**：写了什么、闸门报了什么、平台返回了什么、决定了什么、排除了什么、还开着什么。

## 二、`DECISIONS.md` 的条目形状

每条至少四段，缺一段的那条不算决策：

```
## D-NN 一句话题目

**触发。** 什么情况让这个问题必须被决定。

**决定。** 决定了什么。

**为什么。** 理由 —— 这一段是这条记录存在的意义。没有它，未来的人无从判断它是否适用于自己。

**什么会推翻它。** 具体的可观察条件。
```

**「什么会推翻它」不是客套。** 它是这条记录的解约条款：没有它，一条曾经正确的决定会永远正确下去。

## 三、读数层的证据等级（本项目的特有纪律）

平台读数在**本项目里全是用户在会话中的转述** —— 本机没有该平台的登录态，读不到报告文件也读不到截图。
所以：

- 写读数时，**把「它是转述」写进那一层**（回填文件里那条是 `_真实性说明`）。
- `E19b` 校验自洽（等级是否等于映射表算出、五维均分×10 是否与总分相符），
  它**抓的是转述错字，抓不出整份报告读错**。这句话要跟着读数一起出现。
- 能拿到导出件或截图时，补进 `_原报告来源`。
- **不要**把一条转述升格成实测。可复核程度低于一次实测读数，但高于推理 —— **如实写这个位置**。

## 四、写之前先读那个文件的头

`INVENTORY.md` 与 `PROJECT.md` **今天都没有受管区块** —— 两份文件里一个 `<!--` 都没有。
本工作区**唯一**带受管区块的是 `products\<剧名>\bible\README.md`（`asset-manifest.mjs:117` 写的就是它，
`BEGIN`/`END` 两个显式标记，见 `asset-manifest.mjs:35-36`）。
**约定仍然照旧：往一个文件里写之前，先读它的头。**
**往一个文件里写机器内容之前，先读它的头**，确认它的格式与它声明的不变量。

受管区块的写法：**只改两个显式标记之间的字节**，并断言标记之外的字节逐一不变。标记缺失或有头无尾时**报错拒绝**，
不要猜 —— 那份文件归用户所有，覆盖它是数据丢失，不是格式问题。

## 五、完成一个里程碑时的自查

- [ ] 我写下的每条「结论」都能指出它是从哪个文件、哪条命令、哪次读数来的
- [ ] 没能核实的，我写成了**开放问题**而不是结论
- [ ] `DECISIONS.md` 我是**追加**的，没有改动任何既有条目
- [ ] 我没有把平台的规则冻结进记忆层，而是留了出处
- [ ] 我把现在已经假了的旧说法删掉了，而不是让它在原地被矛盾
- [ ] `评估报告-回填.json` 的 `_待我做的` 反映了当前真实的阻塞项
